Configuration du certificat

Génère un JSON horodaté BIP-nom-du-bip-config-date.json pour les confirmations de présence.

Enregistré dans ce navigateur. Repris sur les certificats.

Saisie

  1. Saisissez un chemin relatif.
  2. Ou chargez un fichier avec le bouton.
  3. Ou déposez le fichier sur le champ.

Fichier

  1. Formats acceptés : PNG, SVG, JPEG, GIF.
  2. Le fichier est chiffré, puis enregistré dans upload/ sous un nom aléatoire.
  3. L’adresse contient la clé. Sans elle, le fichier est illisible.
  4. Le JSON et ce navigateur conservent cette adresse.

Personnes à certifier

Saisie

  1. Glissez/déposez un fichier .txt.
  2. Ou déposez le JSON enregistré : il recharge la liste et les champs.
  3. Une ligne égale une personne.
  4. Modifier le texte reconstruit le tableau.
  5. Corriger une cellule réécrit la liste.

Ordre

  1. Écrivez : nom, prénom, établissement d’envoi, pays.
  2. Les mots en capitales forment le nom.
  3. DE LA FONTAINE Jules donne le nom DE LA FONTAINE.
  4. Le premier mot qui n’est pas en capitales ouvre le prénom : Jules.
  5. Si aucun mot n’est en capitales, le premier mot est le nom.
  6. Nom et prénom suffisent.
  7. L’établissement d’envoi est facultatif.
  8. Le pays est facultatif.
  9. Le pays est le code ISO d’un pays du programme Erasmus+.
  10. Le Royaume-Uni et la Suisse ne sont pas encore dans la liste.

Rôle

  1. Sans titre, la personne est étudiante.
  2. Students recoche les lignes suivantes.
  3. Une ligne sans virgule contenant « teacher », « enseignant », « prof » ou « professeur » décoche les noms suivants.
  4. Dans le tableau, un clic passe de Étud. à Prof.
